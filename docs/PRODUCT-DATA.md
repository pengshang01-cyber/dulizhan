# 产品标准资料

每款试点使用 `data/product-specs/<网址片段>.json`。编辑器可用同目录的 [JSON Schema](../data/product-specs/schema.json) 校验字段。网站只发布当前目录中已公开产品的资料。

## 现场记录

1. 先记产品型号、拍摄规格、测量日期及单位。同一款有多个尺寸时分别填写。三视图使用相同的实物规格；盒盖注明对应盒身。
2. 圆杯测底部外径、卷口外径和总高。方杯和盒子测底部与口部的外长、外宽及总高。圆角半径按底部、口部单独记录。平片和底板记录外长、外宽或直径。尺寸使用毫米，净重使用克。
3. 数完整一圈的褶纹。卷边宽度是内沿到外沿的横向距离，厚度是最上缘到最下缘的距离。纸厚测单层、无褶、无卷边处。克重和重量分别填写。
4. 包装引用原规格表的包装方式、装箱方式和外箱规格。外箱单位需有依据。颜色沿用经核对的名称，色号与 HEX 需有确认过的色表。把整理过的包装、颜色文件各放入 10、11 号档案。
5. 逐项记录外壁、底面、内壁和盒盖能否印刷。工厂确认印刷色数、出血及安全区之后录入。核实平张裁切、搭接或者折线时，保留工厂确认的刀版依据。

## 字段和状态

| 字段 | 内容 |
| --- | --- |
| `slug` / `shape` | 与产品网址一致。区分圆形、方形、长方形卷口杯、纸托、盒子、纸片、底板和复杂杯型。 |
| `variants` | 每个规格包含单独的 `body`、配盖状态和 `lid`。几何、褶纹、卷边、材料、重量及包装分别记录。 |
| `colors` / `printAreas` | 颜色名称及可核实色值。印刷能力按部位核实。 |
| `photos` / `rotation` | 01–12 号原始资料与拍摄角度。转盘资料记录帧序核对状态。 |
| `modelAppearance` / `colors[].display` | 试点模型使用的样杯颜色、实拍轮廓参考和显示色来源。工厂确认的色号和 HEX 单独记录。 |
| `sources` | 来源索引。写清厂方实测日期及型号、规格表工作表和行号、图册页码或审核过的照片记录。 |

`verified` 值需要 `source` 指向 `sources` 中的记录。`missing` 用于未收到的数据，`pending` 用于正在核实的字段，二者均用 `null`。实测与规格表发生冲突时同规格以实测为准，并在审核报告注明旧值和新值。单位、色值、圆角或工艺参数无法核实的项目留空。

## 照片与技术图

按 [产品图片工作室](skills/product-image-studio/SKILL.md) 保留原照，只处理副本。01、02、03 用固定位置拍摄正面、侧面及严格俯视。04 拍底部，05 拍 45° 俯视，06 拍内部，07 拍细节，08 在同一个测量平面放直尺，09 拍实际叠放。12 号从正面开始等角旋转并编号，或提供固定机位的完整一圈视频。

在项目目录运行 `npm run product:drawings` 可用已核实数据重出 Schema、技术 SVG、1600px PNG 和内部展开参考。访客在规格参数中展开三视图后，可点击查看原尺寸 SVG。

正投影图用同一单位比例。缺少圆角半径时，虚线表示核实过的外接尺寸。标明照片拍摄角度与叠图量测依据。印刷展开参考与批量制版刀模分开校核，工厂需确认裁切路径、印刷区域、出血、安全区及真实的生产版型。

产品页及 [llms.txt](https://junbeili.com/llms.txt) 链接到 `/data/product-specs/<网址片段>.json`。公开 JSON 提取核实过的规格、材料、颜色和包装值；本地素材路径、印前资料、缺失和待核实字段保留在内部标准文件内。

## 三维展示

运行 `npm run models:build`，按含 `modelAppearance` 的产品记录生成 `public/models/<网址片段>/<规格>.glb`。规格用毫米录入，模型按米输出。配盖需要盖身两端及高度资料。只核实盒身的规格可单独展示盒身。

Blender 从这些记录读取外包尺寸、实测褶数和卷边。侧壁、折回的纸片、卷管、内壁和外底可以从不同方向查看。长方盒的两个三维规格均展示盒身；配盖尺寸和技术图在规格区查阅。方杯按工厂核实的四角各五道计入总褶数。实拍能辨认而没有测值的弯折起伏、方杯圆角和纸厚只用于外观建模，资料文件保留原核实状态。

方杯和纸盒的 UV0 `Print` 依照各自的侧板和底面。5039 圆杯的 UV0 对应下述整张原料纸片，UV1 `PaperDetail` 单独承载高模烘焙的 768 × 768 切线法线。[本地 Blender 路径与构建命令](../README.md#重新生成试点产品的-3d-模型)

颜色优先使用工厂确认的 HEX。照片显示色记录取样来源，供屏幕预览。印制前由工厂核准印刷面、刀版和印刷余量。

模型更新后，安装 Playwright Chromium，在仓库运行 `node --experimental-strip-types scripts/models/render.ts`，重出统一角度封面和四视角审核图。产品媒体区依次提供模型、两张整理过的样品实拍及一张对应规格的尺寸对比。

## 5039 原料纸片与成型

工厂确认 5039 从直径 **143 mm** 的一张圆片成型。对应产品技术 JSON 的 `blank` 只适用于 `variant=5039`。纸片来源为 `factory-blank-5039`。杯底径 50、口部外径 69、高 39、卷边宽厚各 2 mm 和 24 道褶均来自工厂实测。

| 分区 | 原片半径 mm | 推导 |
| --- | --- | --- |
| 杯底 | 0–25 | 底径的一半，保持平面毫米比例 |
| 杯壁 | 25–65.1404 | 斜高为 √(39² + (34.5 − 25)²) = 40.1404 mm |
| 卷边 | 65.1404–71.5 | 纸片剩余 6.3596 mm，沿直径 2 mm 的卷管约绕 1.012 圈 |

用一个圆管周长独立复核，所需原片直径为 2 × (25 + 40.1404 + π × 2) = **142.8471 mm**，与 143 mm 相差 **0.1529 mm**。生成模型保留完整外圈。卷管表面继续取用该段原片的坐标。

杯壁位置从底到口按比例 `f` 取 0–1。原片半径 `r = 25 + 40.1404f`，成型名义半径 `R = 25 + 9.5f`。整圈投影与原片周长之比为 `R/r`，每褶收入纸长 `2π(r−R)/24`。每道褶先向前、折回半份多余纸长，再叠向前方。外露段沿环向的纸面长保留，层间深度和褶距沿用 M19 的实拍外观。具体折峰方位和叠压深度均为预览近似值。

| 杯壁位置 | 投影/原长 | 每褶收入 mm |
| --- | --- | --- |
| 底 | 1.000 | 0.000 |
| ¼ 高 | 0.781 | 2.005 |
| 半高 | 0.660 | 4.011 |
| ¾ 高 | 0.583 | 6.016 |
| 口 | 0.530 | 8.022 |

UV0 将同一个纸面点写为圆片在 143 mm 正方形中的归一化坐标。纸片中心为 (0.5, 0.5)，杯底、外壁、折层和卷边之间连续。纸张背面用独立材质控制着墨。印刷面默认外侧，出血和安全区各预留 3 mm，三者都须工厂签样确认。两种语言的 SVG、PDF 和定制器使用同一套分区与折带计算。[5039 定制器说明](CUSTOMIZER.md)
