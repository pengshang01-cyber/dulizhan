### 询价清单（前端）

- 按 `slug` 去重，首次加入数量为 1；持久化条目严格为 `{ slug, sku, title, category, quantity }`。角标统计产品种数，独立于 pcs 数量。
- Add 按钮再次点击移出；同页相同产品按钮与角标通过 `inquiry:change` 同步。刷新、正常跨页导航和后退缓存恢复状态。
- 清单页数量修改即时保存合法值，输入节点保留以维持焦点。0、负数、小数、空值、指数形式及超过安全整数范围的值不写入清单，显示简短提示。
- localStorage 属性访问、读取及写入均捕获异常；不可用时当前页面仍可增删和修改数量，离开页面后不承诺保留。写入失败后不再从旧存储覆盖当前操作。
- 存储数据校验分类、路由片段及字段，过滤无效数据、重复项；动态内容用 textContent。损坏 JSON 不导致页面报错。
- 继续按钮为 `/contact/?from=inquiry#quote`。M3 仅交付前端清单，邮件、表单提交及成功清空列入 M5。

## 4. 偏离与新增依赖

- 按用户要求扩展 M3 前端清单并更新 M5 计划；未实现 M4 页面内容或 M5 表单 / 发信。
- 当前 Astro 使用 Content Layer API：定义仍放在 PLAN 指定的 `src/content/config.ts`，通过 `src/content.config.ts` 导出，使用 glob loader、schema、getCollection 和 render；未降级框架。[Astro 官方说明](https://docs.astro.build/en/guides/content-collections/)
- `customizable` 允许 boolean 或 TODO_，示例用 TODO_，以满足所有具体产品参数保持占位的要求；`featured` 和 `order` 是页面组织元数据。
- 原仓库没有独立产品详情正文模板，三份 Markdown 均以 Custom options / Packaging / Applications 组织待补内容；参数、颜色、FAQ 等由 frontmatter 驱动。
- 新增开发依赖 `vitest@5.1.0`（MIT），使用 Node 环境 mock 浏览器接口，无新增 UI 框架或 jsdom；增加 npm test，并纳入既有 CI。
- Header 的完整导航从 xl 显示；较窄屏幕使用菜单。手机隐藏装饰品牌图形以保留品牌文字、Inquiry、Get a Quote 和菜单。
- 产品卡片使用覆盖卡片区域的标题链接，询价按钮独立于链接，避免嵌套交互控件。
- 为验证 schema 的临时 Markdown 和测试构建输出不提交。图片继续复用本地 Placeholder 资源，经 Astro 输出 WebP，不新增产品实拍或 AI 图。
