### 统计验证方法与边界

`scripts/seo-browser-qa.ts` 在独立目录构建内存测试配置，使用 G-TEST123、明确的测试联系方式及 Placeholder 二维码；不写入生产 site.json。Google 脚本 / 请求、Turnstile 与询盘 POST 均由浏览器拦截。检查官方 gtag 的 arguments 命令格式、language 参数、个人信息未被附加、拒绝 / 撤回 / 无配置 / 存储失败时零统计请求。成功提交只模拟 API 返回，不发送邮件。

验证的是网站加载和事件行为；未配置真实 GA 属性，也未向真实 GA 发送数据或声称 GA 控制台已收到事件。上线填写 ID 后，可按 README 在可访问 Google 的网络中完成实时报告验收。页面 URL 统计不包含查询参数与 hash，不传表单姓名、邮箱、电话、微信或留言。
