精修使用源照片副本，保持原有视角、件数、印花及金属工艺。双面金样图的模型试修改变了金箔反光和折痕，因此改用传统处理。放大核对杯沿、褶纹和色泽后才采用通过的稿件。花朵杯、浅色杯及金属花边杯中未通过背景和边缘检查的照片保留原图。

图册补图为烫金机制杯、细长条金卡垫、方形金托、树叶形金卡垫、方形慕斯托、纸质甜品杯、长方形淋膜纸盒、光面花边蛋糕板。按中文图册的品类与款式进行对照，英文图册用于交叉核对。页面只引用裁出的产品图，必要的规格仍从产品数据读取。裁切排除了页眉、表格、品名标注和画框。两本原 PDF 位于 Git 忽略目录。

场景图仅用于详情页图库辅图，显示“应用特写”或“商业陈列”，不进入封面与 Product JSON-LD。复核中退回了圆形 PET 托的两张生成稿（杯口、褶纹不符）、披萨盘的两张生成稿（印花细节不一致）和两张旧场景（红色防油圆杯比例变化、圆形淋膜浅杯印花色调变化）。同一花朵杯特写位置使用复核通过的旧绿杯场景。D 盘其余系列沿用 [M10 对应与排除记录](M10.md#d-盘未采用的系列与弃用数量)，本轮没有放宽对应条件。
