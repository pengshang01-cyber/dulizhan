## Blender 建模

### 建模与复现

本机使用 Blender Foundation 签名的 Blender 5.3.0，构建号 `02f0899d78e3`，Windows 路径为 `C:\Program Files\Blender Foundation\Blender 5.3\blender.exe`。运行 `npm run models:build` 从三份 M18 JSON 读取毫米尺寸。后台入口使用 `--background --factory-startup --disable-autoexec --python`，工厂可通过 `BLENDER_PATH` 指定安装位置。[本地配置说明](../../README.md#重新生成试点产品的-3d-模型)

- [forming.py](../../scripts/blender/forming.py) 生成具有两面的连续纸张截面。侧壁外折峰后向上一片纸的背面折回，再沿下一面展开。固定种子 5039 控制褶距、锐边倾角和压痕的微小差异。方杯平面与角部成组的折线分开建模，长方盒将搭边集中在短壁两端。中号透明盖保留独立的裙边、台阶、斜肩和盖顶。
- [model.py](../../scripts/blender/model.py) 建立 Blender 网格，分别为印刷与法线建立 UV。卷管的纸片卷过一圈后回收，折峰接触卷管处局部收紧、隆起。杯外底、脚边和外壁共用材质，内部平底与内壁共用淋膜材质。网页里向下翻转时增加下方白色反光板的补光。
- 使用 Cycles 在 CPU 上将有纸纤维和压皱起伏的高模投射到低模，分别展开相邻薄面，烘焙一张 768 × 768 的切线法线图。圆杯为 1,144,320 → 57,600 个面，方杯为 882,080 → 44,400 个面，盒身为 643,680 → 32,400 个面。UV0 对应印刷展开面，UV1 供微表面法线使用，并作为导出切线的计算基准。回归测试从网格复算 UV1 的 U 轴方向。Meshopt 对位置使用独立分量的 21 位精度，避免在薄叠层处产生重边。连续两次完整的单线程烘焙及导出，四份文件 SHA-256 逐一相同。 [Blender 法线烘焙](https://docs.blender.org/manual/en/latest/render/cycles/baking.html) · [glTF 导出](https://docs.blender.org/manual/en/latest/addons/scene_gltf2.html)
