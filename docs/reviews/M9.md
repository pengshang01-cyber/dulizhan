## 4. 偏离与新增依赖

- 上传文件名为“Junbeili 独立站资料填写表（按1688类目）.xlsx”，已核对内容与工厂指定工作簿一致。Git 保留二进制文件原样移动记录。
- 索引注明了材质、形状或工艺的证据边界。材质未细分的淋膜款与明确 PET 淋膜的款式分组维护。方形和长方形的纸片分别归组。
- 新增开发依赖 `read-excel-file@9.3.20`，仅在离线导入脚本读取 XLSX，包括中文工作表和原始数字类型。已验证 npm registry 完整性字段，使用锁定版本及 `npm ci --ignore-scripts`，锁文件审计报告为 0 个漏洞。[上游仓库](https://gitlab.com/catamphetamine/read-excel-file)

### Schema 改动

- `sizes[].specification` 是可选双语文字，表示非圆形长宽、卷长和该规格克重。底径、高度、口径继续接受正数和旧 `TODO_` 占位，新增允许留空。表格只显示有资料的列。
- `gsm` 保留数值和 TODO 类型，增加范围或多个克重选项。详情统一显示 `g/m²`。
- 产品级 `moq`、`leadTime`、`packaging`、`cartonSpec` 可留空。页面从网站设置读取起订量与交期的默认说明，报价包装、起订量与外箱放在对应尺寸的双语包装详情里。
- 未知定制状态使用显式占位，详情显示有确认结果的定制状态。颜色和图案只写表里有值的选项。
